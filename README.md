# Fast-Decoupled-Load-Flow-FDLF-Study-for-a-System-with-Any-Number-of-Bus-
This project focuses on the implementation and study of the Fast-Decoupled Load Flow  (FDLF) algorithm for power flow analysis in electrical systems independent of the number  of buses.  The FDLF algorithm is implemented using MATLAB to efficiently analyze 
systems with any number of buses. IEEE standard test cases are utilized, and comparisons 
are done with Power System Analysis Framework (PSAF) to validate the accuracy of the 
implemented method. Results illustrate the effectiveness of the FDLF algorithm in 
predicting voltages and angles, with slight discrepancies detected in reactive power 
calculations as the number of buses grows. This method reduces the dependency of load 
flow study on reactive power calculations. Through a combination of theoretical analysis, 
algorithm development, and simulation experiments, the project intends to elucidate the 
effectiveness and practicality of FDLFS in real-world scenarios.
